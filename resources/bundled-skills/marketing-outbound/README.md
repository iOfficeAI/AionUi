# B2B-Outbound-Skills für Claude Code

17 installierbare Skills, die Claude Code **deinen exakten Outreach-Workflow** beibringen — von der
Firmenanalyse über Copy bis zum Reply-Rate-Tuning. Deutsch, **DSGVO/UWG-aware**, ein
zusammenhängender Workflow statt 17 Einzelteile. Gebaut von **Command EVE / FYN Labs**.

> Doppelte Nutzung: dieser Ordner ist gleichzeitig der **kostenlose Lead-Magnet** (zippbar +
> weitergebbar) **und** eine echte Fähigkeits-Bibliothek, die Command EVE später für Kunden fährt.

## Installation
Kopiere die Skill-Unterordner nach `.claude/skills/` deines Projekts (Claude Code lädt sie
automatisch). Lege deinen `outreach-brief.md` ins Projekt-Root — `session-start-hook` zieht ihn in
jede Session.

## Rechtlicher Rahmen (Deutschland) — pragmatisch
Formal verlangt **UWG §7(2)** für Cold-Email streng genommen Opt-in (ohne B2B-Ausnahme), und
Cold-Call gilt nur unter „mutmaßlicher Einwilligung". In der **Praxis** wird B2B-Outbound — vor allem
**Telefon und LinkedIn** — breit gemacht und akzeptiert; real abgemahnt wird fast nur, wer spammt
oder nach einem „Nein" weitermacht. Die Skills sind darauf ausgelegt: **relevant statt Volumen**,
sauberer Opt-out, im Zweifel Telefon/LinkedIn für den Erstkontakt. Das ist Orientierung, kein
Gesetzes-Gate — **du entscheidest** und bleibst verantwortlich. Die Skills weisen nur an den
relevanten Stellen kurz darauf hin, ohne dich auszubremsen.

| 04 | `icp-definer` | Won/Lost + Churn | ICP aus Pipeline-Evidenz + Disqualifier |
| 05 | `persona-definer` | Titel, Calls, Alltag | Buyer-Persona: Sprache, Druckpunkte, Ton |
| 06 | `competitor-finder` | Wettbewerber + Notizen | Landmine-Fragen + Handling-Skripte |
| 07 | `tam-sam-som-sizer` | ICP + Geografie | TAM/SAM/SOM mit Methodik + Annahmen |
| 08 | `pain-identifier` | Won-Calls + Versuche | Top-5-Pains in Buyer-Sprache, gerankt |
| 09 | `copywriting-first-touch` | Name, Signal, Angle | Signal-geführte Erstansprache < 75 Wörter (consent-aware) |
| 10 | `copywriting-follow-up` | Erster Touch + Persona | 2–5 Touches, je ein anderer Angle |
| 11 | `copywriting-linkedin-dm` | Profil + Fundweg | Vernetzung + 1. & 2. DM, je 2 Varianten |
| 12 | `cold-call-script` | Ziel-Titel + Firmentyp | Opener, Permission, Pain, Value-Bridge + Einwände |
| 13 | `pipeline-analyser` | Pipeline / CRM | At-Risk-Flags, Ursachen, nächste Aktion pro Deal |
| 14 | `reply-rate-analyser` | Sequenz-Performance | Benchmark, Ursache pro Touch, A/B-Tests |
| 15 | `n8n-workflow-builder` | Workflow + Tools | Node-Struktur, API-Endpoints, Error-Handling |
| 16 | `outreach-strategist` | Situation, Ziel, Constraints | Virtueller Head of Growth — koordiniert die Skills |
| 17 | `session-start-hook` | `outreach-brief.md` | Lädt den Brief in jede Session — null Wiederholung |

## Der Klammer-Trick: `outreach-brief.md`
Skill #01 schreibt ihn, Skill #17 lädt ihn in jede Session. Claude kennt **Angebot, ICP, Persona,
Wettbewerb** sofort — du erklärst es nie wieder.
