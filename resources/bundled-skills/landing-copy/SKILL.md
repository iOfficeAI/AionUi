# Landing Copy

A landing page is not a brochure — it is **one ICP, one frame, one promise**, arranged so a warm visitor who already
clicked says "this is for me" before they say "this is a pitch". This is **inbound**: the reader chose to be here, so the
job is *clarity and resolution*, not interruption (that is marketing-outbound). The okara discipline: lead with a frame
the buyer already understands, **show the one result instead of claiming it**, and reveal depth progressively so nobody
drowns. Specificity is the trust signal; completeness is the churn signal.

## When to use
- Writing or reworking a landing / sales / product page for a **known ICP**: "write the homepage", "rewrite this page".
- "Make the hero stronger", "the value prop is mushy", "this page doesn't convert", "tighten the headline".
- Building the page for one defined buyer + one use-case — NOT cold/outbound copy (use marketing-outbound for that).

## The method
Build it as layers — frame, hero, sections, discipline-pass. Lock the frame before you write a single line of hero.

1. **LOCK the ICP + the ONE use-case + the value-FRAME.** One buyer, one job-to-be-done, one frame. The frame **anchors
   against the alternative the buyer already knows** — "a whole team for the price of one tool", "your scattered stack,
   replaced", "the agency result without the agency retainer". If you can't name the alternative the reader is mentally
   comparing you to, you don't have a frame yet — pull the ICP's real incumbent from deep-research first.
2. **HERO — earn the scroll.** A **direct diagnostic QUESTION or an outcome headline**: the best questions are
   *insider-diagnostic, forced-yes* (the ICP can only answer "yes, that's me") — and carry **NO euro amount** (price in
   the headline flips "they get me" into "they're selling me"). Run the option-tournament to pick it (generate 15+,
   bracket them, don't fall for the first clever one). Then a **subline that RESOLVES the hook into the promise** (the
   question's payoff in one plain sentence), a single **CTA**, and a **trust-microstrip** under it (the proof that the
   click is safe — "no card", "14 days", a real number).
3. **SECTIONS in okara logic — in this order.** (a) the **value-frame** restated as the reader's world; (b) the **ONE
   result** — *show it with real numbers*, a concrete before/after, never an adjective; (c) **how-it-works in 3 steps**
   (more than 3 reads as complexity = friction); (d) the **confidant/differentiator** — the one thing **no competitor
   can truthfully claim**; (e) **trust/moat**; (f) **proof** (specific, attributable, not "trusted by thousands"); (g)
   **ONE price visible**, every other tier behind a quiet link; (h) **FAQ as objection-handling** — answer the three real
   "no"s, not softballs; (i) **close-CTA** repeating the hero promise.
4. **DISCIPLINE pass — cut until it bleeds clarity.** One ICP, one frame — if a second buyer crept in, delete them.
   **Specificity = trust**: replace every claim with a number or a shown example. **No euro amount in the headline.**
   **Depth is progressive** — the visitor should be able to stop reading at any section and still have the gist; overwhelm
   is churn. Then **validate the headline + frame with icp-persona-panel** before shipping (does the ICP forced-yes the
   question, or does it read as hype?), and pre-mortem the page's single biggest failure mode before you publish.

## Output
- The locked **ICP · ONE use-case · value-FRAME** (with the named incumbent it anchors against).
- The full **page copy in section order**: hero (headline + subline + CTA + trust-microstrip), then value-frame · the
  shown ONE result · 3-step how · differentiator · trust/moat · proof · single visible price · objection-FAQ · close-CTA.
- The **headline option-tournament shortlist** (why the winner beat the runners-up), and **what the persona-panel flagged**.
- The decision it changes: which frame to commit the page to, and the one section most likely to lose the visitor.

## Key discipline
- **Clarity beats completeness.** A page that says one thing perfectly outconverts a page that says everything adequately.
- **Show, don't claim.** "Turns a 3-week launch into a Tuesday" with a real artifact beats "powerful and fast".
- **One ICP, one frame.** The moment you write for two buyers, you persuade neither — split into two pages instead.
- **No price in the headline; one price on the page.** Headline sells the outcome; the visible price is the floor, the
  rest stay behind a quiet link so the page never reads as a pricing table.
