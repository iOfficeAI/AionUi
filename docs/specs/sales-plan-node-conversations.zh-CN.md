# 销售计划审批节点对话约定

销售计划审批工作台为每个审批节点绑定一个专属对话。进入节点不自动生成分析；用户明确选择需要辅助分析后，才创建对话并发起首次分析。

## 对话归属

- 绑定身份由当前账号及业务环境、计划月份、计划类型、审批节点共同确定。
- 同一身份复用同一个对话。组织维度、筛选条件、勾选对象、分页、刷新和快照版本变化不创建新对话，也不自动追加分析。
- 切换到其他节点时显示该节点的对话；切回原节点时恢复原对话。
- “全部节点”视图提示用户选择节点，不创建汇总对话。
- 对话内容由既有会话服务保存。节点与对话 ID 的对应关系保存在本机浏览器存储中；不提供跨设备绑定同步。清理本机存储会移除绑定，但不会删除服务端对话。
- 恢复绑定时校验对话所属 Assistant；最近对话列表未包含绑定对象时，按 ID 单独查询。读取失败提示重试，不自动创建替代对话。

## 首次分析

| 当前情况             | 右侧行为                                             |
| -------------------- | ---------------------------------------------------- |
| 未选择具体节点       | 提示选择审批节点                                     |
| 节点数据正在加载     | 等待可用数据，不创建对话                             |
| 节点无数据或查询失败 | 提示数据不可用，不创建对话                           |
| 节点有数据且尚未绑定 | 询问是否需要辅助分析，提供“需要辅助分析”和“暂不需要” |
| 用户选择暂不需要     | 不创建、不分析，保留稍后开始入口                     |
| 用户选择需要辅助分析 | 创建并绑定对话，附加点击时的工作台快照，发起一次分析 |
| 已有绑定             | 恢复对话；后续分析由用户在对话中主动发起             |

分析只能使用快照内已提供的证据。选中对象、当前页与完整筛选范围汇总必须明确区分；缺失的历史或业务依据不能推断为已取得。辅助分析本身不执行通过、退回或修改计划等业务写入。

## 切换与异常

- 连续点击开始按钮不能并发创建重复对话。
- 创建期间切换节点，迟到的创建结果仍绑定原节点；不会向其他节点发送分析。切回原节点时读取已有对象。
- 若创建完成时节点或快照已变化，不发送过期的首次分析请求。创建出的对话仍保留，用户可在其中主动发起分析。
- 切换节点或离开页面时清理尚未消费的首次分析请求，不因再次进入而重新生成请求。
- 创建失败后由用户明确重试；缺少模型配置时提供配置入口，不循环自动重试。
- 节点模式不提供另建对话或任意切换历史对话的入口，避免覆盖节点绑定。其他页面保留原有对话操作。
- 旧自动生成的历史对话不按名称推断节点归属，也不自动迁移绑定。

## 布局

工作台与 Agent 之间的分隔条支持拖动、方向键调整、双击恢复默认和本机宽度记忆。窗口变窄时按实际可用空间限制宽度；会话绑定变化不重建分隔条。
