# 首页助手标签筛选与星形图标移除

## 变更日期

2026-04-30

## 变更内容

### 1. 首页只显示编程相关的助手标签

在首页引导页面中，助手标签列表由原来的全部预设助手（11 个）精简为仅显示与编程相关的助手（6 个）。

#### 保留的助手（编程相关，`showOnHome: true`）

| 助手 ID               | 名称              | 说明                                     |
| --------------------- | ----------------- | ---------------------------------------- |
| `cowork`              | Cowork            | 自主任务执行、文件操作、多步骤工作流规划 |
| `openclaw-setup`      | OpenClaw 部署专家 | 安装、部署、配置和故障排查               |
| `beautiful-mermaid`   | Beautiful Mermaid | 流程图、时序图、架构图                   |
| `game-3d`             | 3D 游戏生成       | 3D 游戏代码生成                          |
| `ui-ux-pro-max`       | UI/UX 专业设计师  | UI/UX 设计、配色、字体配对               |
| `planning-with-files` | 文件规划助手      | 代码重构规划、项目迁移规划               |

#### 隐藏的助手（非编程相关，不设 `showOnHome`）

| 助手 ID                   | 名称             |
| ------------------------- | ---------------- |
| `word-creator`            | Word 文档助手    |
| `ppt-creator`             | PPT 演示助手     |
| `excel-creator`           | Excel 表格助手   |
| `morph-ppt`               | Morph PPT        |
| `morph-ppt-3d`            | 3D Morph PPT     |
| `pitch-deck-creator`      | 路演 PPT 助手    |
| `dashboard-creator`       | 数据仪表盘       |
| `academic-paper`          | 学术论文助手     |
| `financial-model-creator` | 财务建模助手     |
| `star-office-helper`      | Star Office 助手 |
| `human-3-coach`           | HUMAN 3.0 教练   |
| `social-job-publisher`    | 社交招聘发布助手 |
| `moltbook`                | moltbook         |
| `story-roleplay`          | 故事角色扮演     |

> 隐藏的助手仍可在设置页的助手管理中查看和启用，仅首页标签列表不再展示。

### 2. 移除首页星形图标按钮

移除了首页底部快捷操作栏中的 "点个星吧" 按钮（星形 SVG 图标 + `quickActionStar` 文案），该按钮原来链接到 GitHub 仓库。

## 修改文件

### `src/common/config/presets/assistantPresets.ts`

- `AssistantPreset` 类型新增 `showOnHome?: boolean` 字段
- 为 6 个编程相关助手添加 `showOnHome: true`

### `src/common/types/acpTypes.ts`

- `AcpBackendConfig` 接口新增 `showOnHome?: boolean` 字段

### `src/process/utils/initStorage.ts`

- `getBuiltinAssistants()` 中将 `preset.showOnHome` 传递到助手配置
- `shouldUpdate` 检查中新增 `existing.showOnHome !== builtin.showOnHome`，确保已有安装也能同步更新

### `src/renderer/pages/guid/components/AssistantSelectionArea.tsx`

- 助手列表过滤条件从 `a.isPreset && a.enabled !== false` 改为 `a.isPreset && a.enabled !== false && a.showOnHome`

### `src/renderer/pages/guid/components/QuickActionButtons.tsx`

- 移除 "Give us a star!" 按钮及其星形 SVG 图标
- 从 `hoveredQuickAction` 状态类型中移除 `'repo'`
