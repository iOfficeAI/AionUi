# 06 · 交互流程

> 操作流均以旧版源码为准；每步标注对应代码行为。组件/样式细节见 01–04 文档。

## 流程 1 · 从零创建团队

1. 侧栏「团队」区「＋」→ TeamCreateModal 打开（assistants 模式）。
2. 左栏搜索/滚动助手列表 → 点击助手行（＋）→ 出现在右栏「已选成员」，首个成员自动任 Leader。
3. 点 crown 切换 Leader；点 ✕ 移除（删 Leader 自动移交首位）。
4. 填团队名（必填）、选工作空间（可选）。
5. 「确认创建」（disabled 直到：名称非空 + ≥1 成员 + 有 Leader）→ 校验三连 → 逐成员解析默认模型 → `team.create` → 成功关弹窗、刷新侧栏、跳转 `/team/{id}` → 进入 warmup（流程 6）。

## 流程 2 · 调用专家团建团

1. 创建弹窗切「专家团」Tab → 浏览/搜索（旧版搜索不过滤）预设卡片。
2. 选中卡片 → 右栏预览（成员/简介/tags/示例）。
3. 点卡片「调用」或预览底部「调用此专家团」（有缺失成员时禁用）→ **切回 assistants Tab**：团队名=预设名、成员=预设成员（缺失跳过）、Leader=预设 Leader（回退首位）。
4. 用户可继续增删成员/改 Leader/改名/选工作空间 → 同流程 1 第 5 步。

## 流程 3 · 专家团 CRUD

- **新建**：专家团 Tab「新建」→ 编辑器（zIndex 10001 叠层）→ 填名称*、分类、简介、tags、示例、成员*（含 Leader）→ 保存（三连校验）→ 乐观插入列表首位。
- **编辑**：卡片「⋯」→「编辑」→ 回填表单 → 保存 → 列表原位更新（version+1）。
- **删除**：卡片「⋯」→「删除」→ Modal.confirm（danger）→ 确认 → 列表移除；若正被选中，预览回到 selectHint 空态。
- 全部乐观更新：界面即时反馈，后台失败回滚。

## 流程 4 · 团队页加成员（含「告诉 Leader」）

1. 胶囊栏「＋ 添加成员」→ 下拉面板（标题「添加成员」+ 副标「同一助手可被反复添加」）。
2. 搜索并点击助手 → 行内 Spin → `addAssistant`（role=teammate）→ 关面板、切到新成员 tab。
3. 失败 → Message.error，面板保持。
4. 「没有合适的？」→「告诉 Leader →」→ 切 Leader tab + Leader 发送框预填「帮我在团队里加一个擅长 ___ 的成员」→ 由 Leader 在对话中创建临时队员。

## 流程 5 · 胶囊栏成员管理

- 切 tab：点击胶囊（并行视图滚动+闪动定位该列）。
- 改名：双击/✎ → 内联编辑 → Enter 提交 / Esc 取消。
- 排序：hover 出手柄 → 水平拖拽（Leader 固定首位不参与）。
- 移除：✕ → Modal.confirm（工作中成员用强措辞）→ 确认移除。
- warmup 进行中：以上增删改全部禁用。

## 流程 6 · 团队 warmup（进入团队页）

1. 进入 `/team/:id` → 遮罩覆盖对话区（列抬头保持可点）。
2. 后端 Leader 优先、错开 3s 逐个唤醒：头像 暗淡 → 呼吸（pending）→ 点亮（ready，Leader 先亮）。
3. 全员 ready → 揭罩进对话。
4. 失败 → 失败卡：
   - teammate 失败：抬头切模型，或胶囊栏移除该成员，再点「重试」；
   - Leader 失败：只能抬头切模型后「重试」（Leader 不可移除）；
   - 多失败：逐行核对成员与原因。
5. 失败成员胶囊头像同步标红（灰化+红环+!），便于定位。

## 流程 7 · 临时团队发起（会话 → 团队）

1. 普通会话抬头「团队协作」（👥）→ AgentSelectorModal。
2. 搜索并选中一个助手 → 回显条「已加入」→ 确认（提交中转圈、禁关）。
3. 成功 → 当前会话关联团队（**会话路由不变**），抬头出现 TeamStatusCard；团队进入侧栏（Comment 图标 +「临时团队」Tooltip）。
4. 点状态卡 → 进入 `/team/:id`（团队页标题行多出「←」可回源会话）。

## 流程 8 · 临时团队解散/删除

- 解散（后端语义）：状态卡变灰点 +「已解散」，点击回源会话。
- 删除团队：侧栏菜单 → Modal.confirm（warning）→ 删除后临时团队回源会话路由，普通团队回首屏。

## 流程 9 · 视图切换与全屏

- 「视图 并行/单聊」分段钮（成员>1 才显示）↔ 列抬头 ⛶，两者同一状态源，按团队持久化。
- 单聊 = 全屏当前选中成员；并行 = 多列均摊（1 1 400px），超宽横滚+snap+两侧箭头。
