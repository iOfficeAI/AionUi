## 1. 页面骨架

```
TeamPage（TeamTabsProvider 每团队一实例）
└── ChatLayout（title=团队名，可重命名；sider=Leader 会话的工作空间栏）
    ├── headerLeading：[origin 返回箭头 Left 16（仅临时团队）] + Peoples outline 16
    ├── headerExtra：TeamViewToggle（仅成员 > 1 时渲染）
    ├── tabsSlot：TeamTabs（胶囊成员栏）
    └── 内容区（relative flex h-full）
        ├── TeamWarmupOverlay（phase ≠ ready 时）
        └── 并行视图：横向滚动多列 AssistantChatSlot
            单聊视图：全屏当前选中成员
```

- `useActiveLease({type:'team'})` 保活；`onRenameTitle` → `ipcBridge.team.renameTeam`。
- 工作空间：优先 `team.workspace`（创建时显式选择），否则回退 Leader 会话临时工作空间；`isTemporaryWorkspace` 同单聊语义。

## 2. 胶囊成员栏（TeamTabs）

bar：`min-h-48px bg-1 border-t border-x border-b border-[color:var(--border-base)]`，testid `team-tab-bar`。
内层：`flex items-stretch`；胶囊列表 `flex items-center gap-6px flex-1 min-w-0 overflow-x-auto py-8px px-12px [scrollbar-width:none]`。

### 2.1 胶囊（TeamTabView）

- 盒：`h-34px max-w-220px pl-6px pr-10px gap-6px rounded-999px border transition-colors duration-150 shrink-0 cursor-pointer`，底色恒定 `bg-[color:var(--bg-2)]`（hover/选中都不改底色）。
- 选中：`borderColor = 成员身份色`（1.5px 视觉一圈描边）；未选中 border transparent。testid `team-tab-{slot_id}`，`data-team-tab-role`、`data-active`。
- 内容：`TeamAgentIdentity`（头像 22×22 圆，名字 `text-13px font-600` 截断，`nameStyle {color: 身份色}`，testid `team-tab-name-{slot_id}`）+ 状态角标。
- 状态角标 `AgentStatusBadge`（overlay：8px 圆，绝对定位右下 -1px，2px `var(--color-bg-base)` 描边环）：

| status | 视觉 |
| --- | --- |
| active | 绿（green-500）+ `animate-pulse` |
| idle / pending / completed | 灰（gray-400） |
| failed | 红（red-500） |
| dormant（从未唤醒） | 空心灰环（transparent + 1px gray-400 border） |

- 待授权徽标：`pendingCount > 0` 时名字前 `‼️`（`text-14px animate-wiggle`）。
- **hover 增宽**（`showHoverActions`）：依次内联出现——
  - 拖拽手柄（非 Leader）：`w-14px h-20px`，`Drag outline 13`，`cursor-grab`（拖动中 `-grabbing`），aria-label `team.reorderMember`，testid `team-tab-drag-{slot_id}`。
  - 改名钮：`w-20px h-20px rounded-6px`，`Edit outline 13`，hover `bg-3`，testid `team-tab-edit-{slot_id}`。
  - 移除钮（非 Leader）：同款，`CloseSmall outline 14`，hover 文字变 `danger-6`，testid `team-tab-remove-{slot_id}`。
- **拖拽排序**（dnd-kit sortable，仅水平轴 `restrictToHorizontalAxis`，激活距离 8px）：Leader 不参与排序（固定首位）；拖动中胶囊 `opacity 0.72`、兄弟胶囊 transform 实时让位；`dragActive` 期间冻结其他胶囊 hover 增宽（防闪烁循环）。
- **改名**：双击胶囊或点 ✎ 进入；内联 `<input>`（`text-15px` 无边框背景透明），打开时 focus+全选；Enter/blur 提交（trim 后为空或未变则还原），Esc 取消。
- **禁用**：仅 warmup 进行中（`warmingUp`）禁用增/删/改名；后端本身串行锁，前端不叠忙碌禁用。

### 2.2 溢出与固定操作区

- 溢出判定阈值 10px；左渐隐 `w-28px linear-gradient(90deg, bg-1, transparent)`，右渐隐同款反向且 `right: var(--team-add-w, 132px)`（避开添加按钮区），均 `pointer-events-none`。
- 「＋ 添加成员」固定最右：容器 `border-l border-[color:var(--border-base)] px-8px`；按钮是**原生 `<button>`（有意的例外）**：内联 style 锁盒模型（appearance none、背景透明、无边框、h-32），`px-10px rounded-8px text-13px font-500 gap-6px`，Plus 15 + `team.addMember.title`；hover `text-[color:var(--brand)] bg-[color:var(--bg-2)]`；禁用仅文字变浅 `text-disabled` + `cursor-not-allowed`，**位置/尺寸/背景两态一致**。testid `team-tab-add-member`。
- 点击 → `TeamAddMemberPopover`（见 04 文档 §4）。

## 3. 视图切换（TeamViewToggle）

- 位置：标题行右侧（成员 > 1 才渲染），testid `team-view-toggle`。
- 结构：标签 `team.view.label`「视图」（`text-12px color-text-3`）+ 分段容器 `p-2px rounded-8px bg-2 gap-2px`。
- 选项钮 `h-26px w-30px rounded-6px`：并行 `AllApplication 15`（`team.view.parallel`「并行」）、单聊 `Square 15`（`team.view.single`「单聊」）；选中 `bg-[color:var(--brand)] text-white shadow-[0_1px_3px_rgba(0,0,0,0.12)]`，未选中 `text-3 hover:text-1 hover:bg-3`。testid `team-view-toggle-parallel|single`，`data-selected`。
- 持久化：`useTeamViewMode(team.id)`，按团队记忆。

## 4. 并行视图（多列）

- 容器：`flex h-full w-full overflow-x-auto overflow-y-hidden [scrollbar-width:none]`，`scroll-snap-type: x proximity`。
- 每列：`flex: 1 1 400px`，`min-width: 400px`（成员 ≤2 时 240px），`scroll-snap-align: start`；除末列外右侧 1px `var(--border-base)` 分隔线。
- 列体背景：`color-mix(in srgb, {身份色} 4%, var(--bg-base))`（极淡身份色提示）。
- **列抬头**（h-40px，`px-12px gap-8px border-b bg-1`）：
  - `TeamAgentIdentity`：彩色名字（身份色，13px/600）+ 头像；抬头不叠身份色底。
  - 右侧 `gap-8px`：`CronJobManager`；模型选择器（非窄屏；ACP 后端用 `AcpModelSelector`，aionrs 用 `AionrsModelSelector`，`max-w-140px` 截断）；全屏切换钮（`p-4px rd-4px hover:bg-[var(--fill-3)]`，`FullScreen/OffScreen 16`）。
  - 列抬头**没有**移除入口（统一在胶囊上）。
- 列体：`TeamChatView`（共享聊天渲染）；conversation 未加载时居中 `Spin`。
- **左右滚动箭头**（列超宽时，阈值 10px）：`absolute w-48px z-20`，渐变（90deg/270deg `var(--color-bg-1) 40% → transparent`）+ 32px 圆钮 `rgba(0,0,0,0.5)` 白图标 `Left/Right 24`；点击切到上/下一成员。
- **点胶囊联动**：`switchTab` + `scrollIntoView(smooth)` 到该列 + 闪动（opacity 1→0→1，`150ms ease-out/in`，尾段 200ms 清理 transition）；页面挂载时对 active 列做一次同款滚动+闪动；程序化切 tab（如「告诉 Leader」）也滚动到可视区。

## 5. 单聊视图

全屏渲染 `activeSlotId` 对应成员；找不到选中时回退 Leader，再回退首个成员。⛶ 钮或胶囊点击切回并行。`isFullscreen` 传列抬头（图标换 OffScreen）。

## 6. 身份色系统

`teamMemberColors.ts`——纯前端展示辅助色，不落库（localStorage）。

```
TEAM_MEMBER_PALETTE = ['var(--brand)', '#5c9ea4', '#b58a5e', '#9481bf',
                       '#c07d97', '#6ba07e', '#4f8ac9', '#c99a4b']
```

分配规则（`assignMemberColors` 纯函数）：

1. Leader 恒定色号 0（品牌色）；
2. 已分配成员**钉死**原色号（增删重排他人不影响）；
3. 新成员取**最小未占用非 0 色号**（优先复用移除释放的空档）；
4. 色板占满按长度取模循环（跳过 0）。

消费点：胶囊名字/选中描边、列抬头彩名、列身 4% 淡底、warmup 头像环光、消息气泡色条/彩名（`colorOfConversation` 桥接，消息侧只有 conversation_id）。未知 slot 回退 Leader 色。

## 7. warmup 遮罩（TeamWarmupOverlay）

触发：进入团队页 `ensureSession` 全员唤醒闸门（`useTeamWarmup`）。`phase: 'warming' | 'error' | 'ready'`（ready 不渲染）。

- 容器：`absolute left-0 right-0 bottom-0 z-20`，**`top: 41px`**（列抬头 40+1 之下——抬头模型选择器始终可点，是失败自救手段）；`background: color-mix(in srgb, var(--bg-1) 80%, transparent)` + `backdrop-filter: blur(3px)`。testid `team-warmup-overlay`，`data-phase`。
- 内容：`flex-col items-center gap-14px px-40px py-28px max-w-420px`。

### 7.1 头像组（最多 6 个，`gap-10px`）

逐个 runtime 信号驱动（`data-status` 可测，testid `team-warmup-avatar-{slot_id}`）：

| runtime status | 视觉 |
| --- | --- |
| 未开始（idle） | opacity 0.35，无环 |
| pending（唤醒中） | opacity 0.75 + `team-warmup-breathe` 呼吸 1.6s（0.55↔0.9）+ 环 `0 0 0 2px color-mix(身份色 55%)` |
| ready | opacity 1 + `0 0 0 2px 身份色` + 外发光 `0 0 12px 2px color-mix(身份色 45%)` |
| failed | opacity 1 + 头像 grayscale + `0 0 0 2px var(--danger)` + 14px 红底白「!」角标（1.5px `var(--bg-1)` 描边） |

头像 34×34 圆（`text-15px bg-fill-2`）。撤除以整体闸门为准（全员 ready 一次性揭罩）。

### 7.2 唤醒中（warming）

- 标题 `text-15px font-600`：`team.warmup.title`「正在唤醒团队…」
- 副标 `text-12px text-t-tertiary`：`team.warmup.subtitle`「正在准备成员」
- 进度条：`w-180px h-4px rounded-2px`，底 `var(--bg-3)`；扫动条 `team-warmup-sweep` 1.4s ease-in-out 无限（宽 20%→60%→20%，`linear-gradient(90deg, var(--brand-hover), var(--brand))`）。

### 7.3 失败（error）

- 标题（15px/600）按失败形态四选一：`team.warmup.memberFailedTitle`（单成员）/ `leaderFailedTitle`（单 Leader）/ `multiFailedTitle`（多成员，带 count）/ `genericFailedTitle`（兜底）。
- 错误框（testid `team-warmup-error`）：底 `color-mix(in srgb, var(--danger) 8%, var(--bg-base))`，字 11px `var(--danger)`；单失败 `max-w-320px max-h-64px px-10px py-6px`，多失败 `w-320px max-h-120px px-10px py-8px flex-col gap-4px` 逐行「**名字（Leader 后缀 `（Leader）`）：精简原因**」。
- 原因精简 `simplifyWarmupError`：剥掉 `failed to warm up rebuilt agent <uuid>:` 噪声与重复的 `Invalid request|Bad request|Internal error:` 前缀；取不到原因回退 `team.warmup.unknownError`「启动失败」。
- 引导（`text-12px text-t-tertiary`）：有可移除 teammate → `team.warmup.memberFailedHint`「可在上方切换其模型，或从顶部移除后重试。」；仅 Leader 失败 → `team.warmup.leaderFailedHint`「可在上方切换其模型后重试。」
- 重试钮（testid `team-warmup-retry`）：`h-32px px-18px rounded-8px bg-brand text-white text-13px font-500 gap-6px` + `Refresh 14`，文案 `team.warmup.retry`「重试」。
- 失败后：胶囊增删改名解禁；失败成员胶囊头像标红（grayscale + 红环 + 12px「!」角标，`data-testid team-tab-failed-{slot_id}`）。

## 8. 团队对话空状态（TeamChatEmptyState）

- 容器：`flex flex-col items-center gap-20px px-24px text-center max-w-360px`。
- 头像 48×48（rd-8 bg-fill-2，图片/emoji/字母兜底三种形态）。
- 名字 16px/600（用身份色）；副标（testid `team-chat-empty-state-subtitle`，13px t-secondary）：Leader → `team.emptyState.leaderGreeting`「你好，我是 Leader，负责理解你的目标并协调团队。描述你想做的事，我来安排。」；成员 → `team.emptyState.memberGreeting`「你好，我是团队成员，我听 Leader 和你的指挥。」
- Leader 另有 3 张建议卡（`flex-col gap-6px w-full`；卡 `flex items-center gap-10px px-14px py-10px rd-10px bg-fill-2 hover:bg-fill-3 hover:border-[var(--color-border-2)]`，emoji 15px + 文案 13px t-secondary），点击预填发送框草稿：`team.emptyState.suggestions.{debate, interview, expert_review}`，另有一张「加成员」卡预填 `add_member` 文案。

## 9. 移除成员二次确认

点胶囊 ✕ → `Modal.confirm`（`okButtonProps {status:'danger'}`）：

- 标题 `team.removeAgent.confirmTitle`「移除团队成员」
- 内容：成员工作中（status=active）→ `team.removeAgent.confirmContentActive`「该成员正在工作中，确定要强制移除吗？其当前工作会被中断。」；否则 `team.removeAgent.confirmContent`「确定将该成员移出团队吗？」
- 成功 `Message.success(common.deleteSuccess)`，失败 `Message.error`。
