# 01 · 专家团预设（Expert Teams）设计规格

> 证据：`packages/desktop/src/renderer/pages/team/TeamPresets/` @ `e3f154559`

## 1. 组件树

```
TeamCreateModal (mode='presets')
├── TeamPresetPicker                    左栏（桌面）/ 上段（窄屏）
│   ├── 标题行：「专家团」+ New 按钮
│   ├── Input.Search「搜索专家团」       ※ 旧版仅 UI，未接过滤逻辑
│   └── 预设卡片列表（可滚动）
│       ├── 卡片 = Arco Button(text) 铺满 + 绝对定位内容层

│       └── 「⋯」Dropdown（编辑 / 删除）
├── TeamPresetPreview                   右栏（桌面）/ 下段（窄屏）

│   ├── 简介段落
│   ├── 擅长领域 Tag 组
│   ├── 缺失警示条（条件渲染）
│   ├── TeamPresetMemberList（成员 + Leader/缺失 Tag）
│   ├── 示例任务列表
│   └── 「调用此专家团」主按钮（mt-auto 沉底）

```

数据层：`useTeamPresets(userId)` —— SWR 读 `ipcBridge.teamPreset.list`；create/update/remove 全部**乐观更新**（先返回本地构造的 preset，`rollbackOnError: true` 后台对账）。`version` 每次更新 +1；`id = uuid(36)`。

类型（`common/types/team/teamTypes.ts:261-285`）：

```ts
TeamPresetMember = { assistant_backend: string; assistant_id?: string; model?: string;
                     assistant_name: string; role: string; order: number }
TeamPreset = { id; user_id; name; icon?; category?; description: string;
               expertise_tags: string[]; example_prompts: string[];
               leader: TeamPresetMember; members: TeamPresetMember[];
               version: number; created_at: string; updated_at: string }
```

## 2. TeamPresetPicker（预设选择器）

容器：`flex h-full flex-col`，`data-testid="team-preset-picker"`。

### 2.1 标题行（两态一致保留）

- 容器 `mb-12px flex items-center justify-between`（非空态加 `gap-10px`）。
- 标题 `team.presets.title`「专家团」：`text-15px font-600 text-t-secondary`。
- New 按钮：`Button type=primary size=mini` + `Plus outline 14`，文案 `team.presets.newPreset`「新建」，testid `preset-picker-new`。

### 2.2 搜索框

- `Input.Search`，placeholder `team.presets.searchPlaceholder`「搜索专家团」，`mb-12px`，testid `preset-picker-search`。
- **规格注记**：旧版未实现过滤（无 onChange/onSearch 绑定），复现时可保留为纯 UI 或补实现——以旧版为准则为纯 UI。

### 2.3 预设卡片列表

- 列表容器：`flex min-h-0 flex-1 flex-col gap-8px overflow-y-auto pr-4px`。
- 每张卡片（`group relative flex items-center rounded-8px`）是**双层结构**：
  - 底层：Arco `Button type=text` 绝对铺满（`absolute inset-0 z-0 h-auto !rounded-8px border px-12px py-10px transition-colors`），负责整卡点击 `onSelect` 与键盘可达（测试要求：Enter 触发选中，不能用 div+role=button）。
  - 内容层：`relative z-10 ... pointer-events-none`，内部按钮单独 `pointer-events-auto`。
- 卡片视觉：
  - 默认：`border-border-2 bg-fill-1`，hover `border-primary bg-fill-2`。
  - 选中：`border-primary bg-[rgba(var(--primary-6),0.08)]`。
- 卡片内容（`gap-10px px-12px py-10px`）：
  - 名称 `truncate text-13px font-500 text-t-primary`；分类（有才渲染）`truncate text-11px text-t-tertiary`。
  - 「调用」按钮：`Button text size-mini` + `Right outline 14`，文案 `team.presets.invoke`「调用」，**默认 `opacity-0`，`group-hover:opacity-100`**，`stopPropagation` 后 `onInvoke`。testid `preset-picker-invoke-{id}`。
  - 「⋯」：`Dropdown position=br trigger=click getPopupContainer=document.body`，菜单两项 `common.edit`/`common.delete`；触发钮 `MoreOne outline 14`，testid `preset-picker-more-{id}`。
- testid：卡片 `preset-picker-item-{id}`，aria-label = 预设名。

### 2.4 空态（0 预设）

标题行 + New 按钮**保留**，下方 `flex flex-1 items-center justify-center` 居中文案 `team.presets.emptyDescription`「创建可复用的专家团，加快团队组建。」（无插画、无字号定义，继承默认）。
另有独立 `TeamPresetEmptyState`（`h-full` 居中 `gap-12px px-20px py-24px text-center`）：Arco `Empty`（同一 emptyDescription）+ `Button primary size-small` + Plus 14「创建专家团」`team.presets.createPreset`，testid `preset-empty-create`。

## 3. TeamPresetPreview（预设详情预览）

容器：`flex h-full flex-col gap-12px overflow-y-auto px-4px py-2px`，testid `team-preset-preview`。

未选中：整栏居中 `text-13px text-t-tertiary`「选择一个专家团以预览详情。」`team.presets.selectHint`。

选中后自上而下：

1. **头部**（`flex items-start gap-12px`）：图标 `size-44px rounded-12px bg-fill-2 text-primary`（`Peoples filled 24`）；名称 `truncate text-16px font-600 text-t-primary`（testid `preset-preview-name`）；分类 `Tag size=small w-fit`（有才渲染）。
2. **简介**：`m-0 text-13px leading-20px text-t-secondary`（testid `preset-preview-description`）。
3. **擅长领域**（数组非空才渲染）：`flex flex-wrap gap-6px`，每 tag `Tag size=small color=arcoblue`。
4. **缺失警示**（有缺失成员才渲染）：`rounded-8px bg-[rgba(var(--danger-6),0.08)] px-12px py-8px text-12px text-[rgb(var(--danger-6))]`，文案 `team.presets.missingWarning`。
5. **成员**：标签 `text-13px font-600 text-t-secondary`「成员」`team.presets.membersLabel` + `TeamPresetMemberList`。
6. **示例任务**（非空才渲染）：同款标签「示例任务」`team.presets.examplesLabel`；列表 `list-none flex-col gap-4px`，每项 `text-12px text-t-tertiary`，前缀 `• `。
7. **调用按钮**：`mt-auto pt-12px` 沉底，`Button primary long`，文案 `team.presets.invokeThisTeam`「调用此专家团」，testid `preset-preview-invoke`；**有缺失成员时 `disabled`**。

缺失成员判定（TeamCreateModal 内）：预设成员的 `assistant_id` 在当前助手目录中找不到（或无 id）即缺失。

## 4. TeamPresetMemberList（成员列表）

`ul list-none m-0 p-0 flex flex-col gap-6px`。每行（`flex items-center gap-8px rounded-6px px-8px py-6px hover:bg-fill-2`）：

- 头像圈：`size-22px rounded-full bg-fill-2 text-t-secondary`，`Peoples outline 14`。
- 名称：`flex-1 truncate text-13px font-500`，默认 `text-t-primary`；缺失时 `text-[rgb(var(--danger-6))]`。
- 缺失 Tag：`Tag small color=red`「缺失」`team.presets.memberMissing`。
- Leader Tag：`Tag small color=orange`，内嵌 `Crown filled 12` +「队长」`team.presets.leaderLabel`（`gap-4px`）。
- Leader 判定：`assistant_id` 与 `order` 同时等于 preset.leader。key = `assistant_id ?? assistant_name` + index。

## 5. TeamPresetEditorModal（新建/编辑弹窗）

壳：`AionModal variant=standard`，class `team-preset-editor-modal`，`width 720 / maxWidth calc(100vw - 72px)`，**zIndex wrap 10001 / mask 10000**（压过创建弹窗 10000/9999），`autoFocus=false`，`unmountOnExit`。
标题：`team.presets.createTitle`「新建专家团」/ `team.presets.editTitle`「编辑专家团」。
内容区：`flex max-h-[70vh] flex-col gap-16px overflow-y-auto px-4px py-2px`。
底部：Cancel（`!h-38px min-w-84px !rounded-8px !px-18px !text-13px`）+ Save（同款 `min-w-100px` primary）。

### 5.1 基础信息栅格

`grid grid-cols-[90px_minmax(0,1fr)] items-center gap-x-14px gap-y-10px`：

| 字段 | 标签 | 控件 |
| --- | --- | --- |
| 名称（必填） | 14px/600 + `*`（`ml-4px text-danger-6`） | `Input h-38 rd-8 text-13`，placeholder「专家团名称」，testid `preset-editor-name` |
| 分类 | 14px/500 | 同款 Input，placeholder「如 Engineering」，testid `preset-editor-category` |
| 简介 | 14px/500，标签 `self-start pt-8px` | `Input.TextArea autoSize {minRows:3,maxRows:6} rd-8 text-13`，placeholder「这个团队负责什么？」，testid `preset-editor-description` |

### 5.2 擅长领域

- 标签 `text-14px font-600 text-t-secondary`「擅长领域」`team.presets.tagsLabel`。
- chips：`flex flex-wrap gap-6px`，`Tag closable`，onClose 移除。
- 输入行 `flex gap-8px`：`Input h-34 rd-8 text-13`（placeholder「添加标签」，testid `preset-editor-tag-input`，Enter 提交）+ `Button secondary small` + Plus 14「添加」`common.add`。
- 规则：trim 后空串不加；**重复值直接清空输入、不入列**。

### 5.3 示例任务

结构同 5.2（标签「示例任务」`team.presets.examplesLabel`）；已每条目 `flex items-center gap-8px`：`flex-1 truncate text-13px text-t-secondary` + `Button text mini`「删除」`common.delete`。输入 placeholder「添加示例任务」，testid `preset-editor-example-input`。同样去重。

### 5.4 成员区

- 标签「成员」+ 必填 `*`。
- 无可用助手：`min-h-112px` 虚线框（`border-dashed border-border-2 bg-fill-1 rounded-8px py-14px text-13px text-t-tertiary` 居中）「未检测到可用的助手」`team.create.noSupportedAgents`。
- 有：`TeamAssistantPicker density=compact testIdPrefix=preset-editor-agent`，候选 = 目录中 `team_selectable !== false` 者。
- 草稿框：`max-h-240px overflow-y-auto rounded-8px bg-fill-1 p-8px` 内嵌 `TeamMemberDraftList`（规格见 02 文档 §4，含 crown 设 Leader、移除、空态）。
- 编辑打开时：成员按 `order` 排序回填；目录中找不到的成员以 `名字 (missing)` 占位、`team_selectable=false`；leader 回填到对应草稿（取不到回退首个）。
- 新增成员时若当前无 Leader，自动把新成员设为 Leader；移除 Leader 后自动移交首个剩余成员。

### 5.5 保存校验与行为

顺序校验，失败 `Message.warning` 顶部提示并中断：

1. 名称为空 → `team.presets.nameRequired`「请输入专家团名称」
2. 0 成员 → `team.presets.memberRequired`「请至少添加一名成员」
3. 无 Leader → `team.presets.leaderRequired`「请选择队长」

保存：成员按当前顺序编 `order`，leader 成员 `role='leader'`（members 中同步标记）；create 走 `createPreset`，编辑走 `updatePreset(id, input)`；失败 `Message.error`「保存专家团失败」`team.presets.saveFailed`；成功 `onSaved(saved)` 关闭弹窗。

## 6. 预设的增删入口与删除确认

- 新建：Picker 标题行「新建」→ `TeamPresetEditorModal`（preset=null）。
- 编辑：卡片「⋯」→「编辑」→ 同一弹窗带 preset 打开。
- 删除：卡片「⋯」→「删除」→ `Modal.confirm`：
  - 标题 `team.presets.deleteTitle`「删除专家团」
  - 内容 `team.presets.deleteConfirm`「确定要删除 "{{name}}" 吗？不会影响已创建的团队。」
  - okText「删除」`okButtonProps {status:'danger'}`，cancelText「取消」
  - 确认后 `removePreset(id)`；若被删预设正被选中，清空选中。
- 「调用」（卡片或预览按钮）→ 回填创建表单，详见 02 文档 §6。
