# 02 · 团队创建弹窗（TeamCreateModal）设计规格

> 证据：`packages/desktop/src/renderer/pages/team/components/TeamCreateModal.tsx`、`TeamCreateModal.module.css`、`memberPicker/*` @ `e3f154559`
> 线框：[assets/team-create-modal-desktop.svg](assets/team-create-modal-desktop.svg)、[assets/team-create-modal-mobile.svg](assets/team-create-modal-mobile.svg)
> 入口：侧栏「团队」区「＋」（testid `team-create-btn`，见 04 文档）。

## 1. 弹窗壳

`AionModal variant='standard'`，class `team-create-modal`：

- 宽：桌面 `900 / maxWidth calc(100vw - 72px)`；窄屏（`layout.isMobile`，<768px）`calc(100vw - 32px)`。
- zIndex：wrap 10000 / mask 9999；`autoFocus=false`；`unmountOnExit=false`。
- `contentStyle { padding: 0, overflow: 'hidden' }` —— 关闭 standard 内容区内边距，让双栏竖分隔线贴边贯穿。
- 标题 `team.create.title`「新建团队」+ 副标题 `team.create.subtitle`「让多个 AI 助手组队协作。建议一个团队只专注一个目标，不同任务分开建。」+ 关闭钮（standard 样式：`button[aria-label="Close"]`，32×32 rd-8 hover:bg-2）。
- 底部：Cancel + `team.create.confirm`「确认创建」（primary，`loading` 转圈；**disabled 条件：`!name.trim() || 0 成员 || 无 Leader`**）。按钮统一 `!h-38px !rounded-8px !px-18px !text-13px`，Cancel `min-w-84px` / 确认 `min-w-100px`，右对齐 `gap-10px`。

## 2. 模式（双 Tab）

`TeamCreateMode = 'assistants' | 'presets'`，默认 `assistants`。Tab 标题：

- `team.create.allAssistantsWithCount`「所有助手 ({{count}})」（count = 当前助手目录长度）
- `team.presets.title`「专家团」

关闭弹窗时全部重置：名称/成员/Leader/工作空间/下拉/模式/选中预设/编辑器状态。

## 3. 桌面双栏（assistants 模式）

根：`grid min-h-0 grid-cols-[minmax(0,1fr)_minmax(0,1fr)]`，`height: min(54vh, 470px); minHeight: 390`，testid `team-create-layout`。

### 3.1 左栏 `team-create-assistant-pane`

`flex min-h-0 flex-col border-r border-border-3 px-20px pb-18px pt-12px`。内嵌 `Tabs justify`，class `styles.teamCreateTabs`（CSS 修复见 §7）。
assistants 面板内容 = 助手选择器（`assistantPicker`）：

- 目录为空：`min-h-112px` 虚线框「未检测到可用的助手」`team.create.noSupportedAgents`。
- 否则 `TeamAssistantPicker density=modal className='min-h-0 flex-1' testIdPrefix=team-create-agent`：
  - 搜索 `AionSearchInput`（常驻描边样式，h-34），placeholder `team.create.searchPlaceholder`「搜索」。
  - 列表：`min-h-0 flex-1 overflow-y-auto rounded-8px bg-dialog-fill-0`，行间距 6。
  - 行（`Button long type=text`，`!h-44px !rounded-8px !px-8px`）：左侧 `AssistantOptionLabel size=large`（头像 30×30 rd-8 bg-fill-2 + 名 14px/500 leading-21 truncate，间隔 12）；右侧固定 30×30 图标位，`Plus outline 16`（行内添加中则换 `Spin 16`，**几何不位移**）。
  - 禁用行（`team_selectable === false`）：`cursor-not-allowed text-t-tertiary`，不加点击；套 `Tooltip`（挂 body，zIndex 10060）显示 `team_block_reason` 或兜底 `settings.assistantTeamUnsupported`。
  - 搜索无结果：Arco `Empty`「未找到结果」`team.create.noSearchResults`。
  - 点击行 = 立即加入右侧成员草稿（同一助手可重复添加）。

### 3.2 右栏 `team-create-details-pane`

`flex min-h-0 flex-col px-20px pb-14px pt-12px`：

1. `TeamMemberDraftList`（见 §4）。
2. `mt-14px shrink-0 border-t border-border-2 pt-14px` → 团队字段（§5）。

presets 模式时右栏换为 `TeamPresetPreview`（见 01 文档）。

## 4. TeamMemberDraftList（已选成员列表）

复用于创建弹窗右栏、窄屏主区、专家团编辑器成员区。

- 标题行 `mb-4px flex justify-between`：
  - 标题 `text-15px font-600 leading-22px text-t-secondary`，文案 `team.create.selectedMembersTitleWithCount`「已选成员 {{count}}」。
  - 右侧默认 = Leader 图例：`Crown filled 13 fill=var(--warning)`（`relative top-1px`）+ `text-12px text-t-tertiary`「= Leader」`team.create.leaderLegend`；窄屏被 `headerAction`（添加成员按钮）替换。
- 辅助说明 `m-0 mb-12px text-12px leading-18px text-t-tertiary`：`team.create.membersHelper`「选择团队成员并指定一个 Leader。同一个助手可被多次选择。」
- 成员框（testid `team-create-member-list-box`）：`min-h-120px flex-1 overflow-y-auto rounded-8px bg-fill-1`；有成员 `flex flex-col gap-6px p-8px`，无成员 `flex items-center justify-center px-14px py-12px`；窄屏追加 `!max-h-[38vh]`。
- 空态（居中两段，`max-w-260px flex-col gap-6px text-center`）：
  - 主文案 `text-13px font-500 leading-20px text-t-secondary`：`team.create.selectAtLeastOneMember`「请至少选择一个助手当团队 Leader。」
  - 次文案 `text-12px leading-18px text-t-tertiary`：`team.create.memberHint`「没有合适的助手当队员？创建后可让 Leader 在对话中创建临时队员。」
- 成员行（testid `team-create-member-draft-{selectionId}`）：`flex h-40px shrink-0 items-center gap-8px rounded-8px px-8px hover:bg-fill-2`：
  - `AssistantOptionLabel size=large`（头像 30×30 + 名 14px/500）。
  - crown 钮（设 Leader）：`!h-26px !w-26px !rounded-6px`；选中态 `Crown filled 15 fill=var(--warning)` + `!bg-[rgba(var(--warning-6),0.16)]`（hover 0.24）；未选中 `Crown outline 15` + `!text-t-tertiary hover:!bg-fill-2`。`aria-pressed`、`data-leader-state=active|inactive`、aria-label「当前 Leader / 设为 Leader」（`team.create.currentLeader` / `setAsLeader`）。
  - 移除钮：`!h-24px !w-24px`，`CloseSmall outline 16`，`text-t-tertiary`，testid `team-create-member-remove-{selectionId}`。
- 规则：任一时刻仅一个 Leader（点击 crown 即切换）；移除 Leader 自动移交首个剩余成员；`selectionId = {assistant.id}-{Date.now()}-{rand36}`（支持同一助手多实例）。

## 6. 创建与「调用预设」回填

### 6.1 创建（handleCreate）

校验顺序（`Message.warning`）：名称为空（`team.create.nameRequired`，并 focus 名称框）→ 0 成员（`team.create.selectAtLeastOneMember`）→ 无 Leader（`team.create.selectOneLeader`）。
随后对每个成员 `resolveDefaultTeamAgentModel` 解析默认模型（单个失败即以 `成员名: 原因` 报错中断），组装 agents（leader/teammate 角色 + model），调 `ipcBridge.team.create`（`workspace_mode: 'shared'`）；bridge 哨兵错误 `__bridgeError` 与异常都走 `getConversationCreateErrorMessage` 显示 `Message.error`。成功 `onCreated(team)` → 侧栏刷新列表并跳转 `/team/{id}`。

### 6.2 调用预设回填（handleInvokePreset）

1. `setMode('assistants')` 切回助手 Tab；
2. 团队名 = 预设名；
3. 成员草稿 = 预设成员按 `order` 排序映射，**目录中找不到的成员直接跳过**；
4. Leader = 预设 leader 对应草稿，取不到回退首个草稿。

（预设侧另有一道闸门：有缺失成员时预览的「调用此专家团」按钮 disabled —— 见 01 文档 §3。）

## 7. Arco Tabs 高度修复（TeamCreateModal.module.css）

**必须原样保留**，否则左栏列表塌缩为 0 高（搜索框可见、行不可见）。要点：

- `.teamCreateTabs` 及 `:global(.arco-tabs-content)` / `-inner`：`display:flex; flex-direction:column; min-height:0; flex:1 1 0%; height:100%; overflow:hidden`。
- `.arco-tabs-header(-nav)`：`flex-shrink: 0`。
- `.arco-tabs-content-item`：**覆盖 Arco 默认 `height:0`** → `height:100%`；`-active`：`display:flex; flex-direction:column; min-height:0; overflow:hidden`（不要加 flex-grow——pane 在横向 slider 里，宽度须保持 100%）。
- `.arco-tabs-pane`、`-item-active > *`：同款 flex 充满。

## 8. 窄屏单栏（mobileBody）

testid `team-create-layout-mobile`，`flex min-h-0 flex-col gap-16px px-20px py-16px`：

- `Tabs`（`shrink-0`，非 justify）。
- assistants 面板：
  - `TeamMemberDraftList`，`headerAction` = 添加成员下拉锚按钮：`Button outline small`，`!h-30px !rounded-999px !px-12px !text-13px`，Plus 14 + `team.addMember.title`「添加成员」，testid `team-create-add-member-btn`；`listBoxClassName='!max-h-[38vh]'`。
  - `mt-16px shrink-0` → teamFields（同桌面）。
- presets 面板：`flex flex-col gap-16px`，Picker 在上、Preview 在下。
- 添加成员下拉（`TeamAssistantPickerDropdown`，受控 `assistantDropdownOpen`）：
  - `Trigger trigger=click position=br popupAlign {bottom:8}`，挂 body。
  - 面板：`w-260px max-h-[min(360px,60vh)] rounded-10px border border-3 bg-dialog-fill-0 p-8px shadow-[0_4px_12px_rgba(0,0,0,0.1)]`，`zIndex 10020`，testid `team-create-assistant-pane`。
  - 内含 `TeamAssistantPicker density=modal searchVariant=inline`（`AionInlineSearchInput` 浅灰无边框）。
  - **选中即关**：选中后下拉收起，成员立刻出现在下方已选列表（即「添加成功」的反馈）。
  - 空目录文案 = `team.create.noSupportedAgents`。
- 交互语言与桌面完全一致（同一 `assistantPicker`/`teamFields` 文案与 testid）。
