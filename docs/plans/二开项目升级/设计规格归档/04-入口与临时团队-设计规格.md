# 04 · 入口与临时团队设计规格

> 证据：`components/layout/Router.tsx`、`components/layout/Sider/TeamSiderSection.tsx`、`pages/conversation/components/AdHocTeam/*`、`pages/team/components/memberPicker/TeamAddMemberPopover.tsx`、`TeamAssistantPickerDropdown.tsx` @ `e3f154559`
> 线框：[assets/sider-team-section.svg](assets/sider-team-section.svg)

## 1. 入口总览

| 入口 | 位置 | 触发 | 目标 |
| --- | --- | --- | --- |
| 新建团队 | 侧栏「团队」区标签行右侧「＋」（testid `team-create-btn`，Tooltip `team.sider.createTeam`） | 点击 | 打开 TeamCreateModal |
| 打开团队 | 侧栏团队项（展开/收起两种形态） | 点击 | 路由 `/team/:id` |
| 临时团队发起 | 普通会话抬头「团队协作」图标钮（testid `collaboration-launcher-trigger`） | 点击 | AgentSelectorModal |
| 临时团队回访 | 会话内 TeamStatusCard | 点击 | `/team/:id`（已解散则回源会话） |
| 添加成员 | 团队页胶囊栏「＋ 添加成员」 | 点击 | TeamAddMemberPopover 下拉 |
| 团队页回访源会话 | 团队页标题行左侧 `←`（testid `team-back-to-origin`，仅 `origin_conversation_id` 存在时） | 点击 | `/conversation/{origin}` |

路由：`/team/:id` 懒加载 `pages/team`，`TEAM_MODE_ENABLED=false` 时 `<Navigate to='/guid' replace>`。

## 2. 侧栏团队区（TeamSiderSection）

### 2.1 展开态

- 标签行（testid `team-section-toggle`，`px-12px h-28px sticky top-0 z-10 mt-8px cursor-pointer`）：
  - 标题 `team.sider.title`「团队」：`text-14px text-t-tertiary font-[500]`，hover `text-t-primary`。
  - chevron `Right 12`：默认 `opacity-0`，hover 行显示；展开时 `rotate-90`；展开状态存 `localStorage team-section-expanded`。
  - 新建钮：`ml-auto -mr-4px size-20px rd-4px hover:bg-fill-4`，`Plus 14`。
- 团队列表（`flex-col gap-2px`）：置顶（`localStorage team-pinned-ids`）排前。每项 = `SiderItem`：
  - 图标 16：普通团队 `Peoples`；临时团队（有 `origin_conversation_id`）`Comment`；运行中 `Spin 16`（覆盖图标）。
  - 选中态：`pathname.startsWith('/team/{id}')` → `bg-active`。
  - 临时团队额外 `Tooltip`：`team.sider.adHocTooltip`「临时团队」。
  - 未读徽标：18px 圆 `bg-danger-6 text-white text-10px font-bold`，`>99` 显示 `99+`；绝对定位 `right-11px` 垂直居中，`group-hover:hidden`。
- 右键/菜单（SiderMenuItem）：置顶/取消置顶（`Pushpin 14`）、重命名（`EditOne 14`）、删除（`DeleteOne 14`，danger，删除中禁用且文案变 `team.sider.deleting`「删除中...」）。
- 删除：`Modal.confirm`（圆角 12、alignCenter、挂 body、`okButtonProps {status:'warning'}`）——标题 `team.sider.deleteConfirm`「删除此团队？」、内容 `team.sider.deleteConfirmContent`「此操作不可撤销。」；确认后 `removeTeam`，成功 `team.sider.deleteSuccess`；若删的是临时团队 → 回源会话路由；若当前正停在被删团队页 → `window.location.hash = '#/'`。
- 重命名：Arco `Modal`（rd-12 alignCenter 挂 body），标题 `team.sider.renameTitle`「重命名团队」；`Input autoFocus allowClear`（placeholder `team.sider.renamePlaceholder`，Enter 提交）；空名禁用确定；成功 `Message.success(team.sider.renameSuccess)`。

### 2.2 收起态（collapsed）

仅在有团队时渲染：`flex-col gap-2px`，每项 `w-full h-40px rd-8px` 居中图标（选中 `!bg-active`，hover `bg-fill-3`）；图标语义同展开态（Spin/Comment/Peoples，Peoples 用 `iconColors.primary`）；未读徽标 `absolute top-4px right-4px`；Tooltip `position=right`（临时团队追加「（临时团队）」）。

## 3. 会话内临时团队发起（AdHocTeam）

### 3.1 CollaborationLauncher

- 会话抬头动作钮：`Button text size-mini`，`Peoples outline 18`，Tooltip `conversation.collaboration.launchTooltip`「团队协作」；`isCreating/isSubmitting` 时禁用。
- 点击打开 `AgentSelectorModal`；确认 → `create(targetAssistantId)` → 成功 `onCreated`（附 target 助手 id/名）并关闭；失败 `Message.error(conversation.collaboration.createFailed)` 且**保持弹窗打开**供重试。

### 3.2 AgentSelectorModal

- 壳：`AionModal variant=standard size=medium`（600×400），标题 `conversation.collaboration.selectAgentTitle`「选择智能体」，testid `agent-selector-modal`。
- 加载中：`h-200px` 居中 `Spin`（testid `agent-selector-loading`）。
- 选中回显条（选中后出现，`mb-16px p-12px rounded-8px bg-fill-2 border`）：`AssistantOptionLabel` + `text-12px text-t-secondary`「已加入」`conversation.collaboration.joinedHint` + 右侧名字 13px/500 截断（testid `agent-selector-selected-name`）。
- 列表：`TeamAssistantPicker density=modal testIdPrefix=agent-selector`（规格同 02 文档 §3.1）。
- 底部：Cancel（testid `agent-selector-cancel`）+ Confirm primary（testid `agent-selector-confirm`）；Confirm 在未选中/加载中/提交中禁用；提交中 `confirmLoading` 转圈且**禁止关闭弹窗**。

### 3.3 TeamStatusCard（会话内团队状态卡）

仅在 `association.team_id` 存在时渲染。`Button text size-mini h-auto`，`flex items-center gap-8px px-12px py-6px rounded-8px bg-2 hover:bg-hover border border-b-base`，testid `team-status-card`，aria-label「打开团队」：

- `Peoples filled 16 text-primary`。
- 标题行（`gap-6px`）：
  - 「团队」`text-12px font-500 text-t-secondary`（`conversation.collaboration.statusTitle`，testid `team-status-card-title`）
  - `AgentStatusBadge overlay=false`（8px→2px 内联点）：解散=completed 灰 / 否则 active 绿
  - 已解散：`text-11px text-t-tertiary`「已解散」`conversation.collaboration.disbanded`
  - 运行中（未解散）：`Spin 10` + `text-11px text-primary`「运行中」`conversation.collaboration.running`
  - 成员数 `Badge`（底 `var(--color-fill-3)` 字 `var(--color-text-2)`）
  - 未读数 `Badge`（默认样式，`offset [-2,0]`）
- 团队名：`text-13px font-500 text-t-primary truncate`（testid `team-status-card-name`）。
- 最新消息预览（有才渲染）：`text-11px text-t-secondary truncate max-w-160px`，tooltip `conversation.collaboration.latestMessage`「最新：{{message}}」。
- 运行详情（运行中且有活跃轮次）：`text-11px text-t-secondary`「{{count}} 个活跃轮次」`conversation.collaboration.runDetail`。
- 点击：未解散 → `onNavigate(team_id)`；已解散 → `onNavigate(origin_conversation_id)`。

## 4. 添加成员下拉（TeamAddMemberPopover / TeamAssistantPickerDropdown）

胶囊栏「＋ 添加成员」→ `TeamAssistantPickerDropdown`（面板规格见 02 文档 §8，此处 `testIdPrefix=team-add-member`、`panelTestId=team-add-member-panel`）：

- 面板标题区（`px-4px pb-8px pt-2px`）：标题 `team.addMember.title`「添加成员」（`text-14px font-600 leading-20px text-t-primary`）+ 副标 `team.addMember.subtitle`「同一助手可被反复添加」（`mt-2px text-12px leading-18px text-t-tertiary`）。
- 行内 pending：选中后该图标位换 Spin，直到 `addAssistant` 完成。
- 选中行为：`resolveDefaultTeamAgentModel` → `addAssistant({role:'teammate', ...})` → 关面板并 `switchTab(created.slot_id)`；失败 `Message.error`。
- **guidanceFooter**（有 Leader 时渲染，`-mx-8px mt-8px px-12px pt-8px border-t border-3`，一根贯穿分隔线 + 文字，不成盒子）：`team.addMember.tellLeaderHint`「没有合适的？也可以直接让 Leader 帮你安排。」+ 链接 `team.addMember.tellLeaderCta`「告诉 Leader →」（`text-[color:var(--brand)] font-500 cursor-pointer hover:underline`，testid `team-add-member-tell-leader`）。
  - 点击：切到 Leader tab + 向 Leader 会话发送框草稿预填 `team.addMember.tellLeaderPrefill`「帮我在团队里加一个擅长 ___ 的成员」（按 Leader 后端选 acp/aionrs 草稿 hook）+ 关面板。
- `disabled`（warmup 中）时强制关面板且不可再开。

## 5. 临时团队 ↔ 团队页的数据关联

- 团队对象带 `origin_conversation_id` 即临时团队（影响：侧栏 Comment 图标/Tooltip、团队页标题行返回箭头、删除后回源路由、状态卡解散跳转）。
- `useAdHocTeamFromConversation` 提供 association / teammates / 最后一条队员消息 / 未读数 / 运行态（`ITeamRunEvent`、`slotWorkBySlot` 活跃轮次计数）。
