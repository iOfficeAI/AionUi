# Export Skill

# Export Analysis Results in Multiple Formats

# Vietnamese Stock Market Analyst | Powered by AI Analyst Lab

## Purpose

Export analysis results in user-requested formats: Marp slides (PDF/HTML/PPTX), CSV data tables, JSON structured data, email-ready brief, or raw data dump.

## When to Use

- **Trigger:** `/export` command
- **Syntax:** `/export [format] [options]`
- **Formats:** `slides`, `pdf`, `csv`, `json`, `email`, `brief`, `data`, `all`

## Export Formats

### Format: slides (Marp)

```
/export slides
```

**Output:** `outputs/deck.marp.md`
**Description:** Marp-formatted slide deck (already generated by deck-creator agent)
**Dependencies:** Full pipeline must have run (L4+ query)

### Format: pdf

```
/export pdf
```

**Output:** `outputs/deck.pdf`
**Description:** PDF export of the Marp slide deck
**Method:** Uses Marp CLI if available, otherwise provides instructions

```bash
npx @marp-team/marp-cli outputs/deck.marp.md --pdf --allow-local-files
```

### Format: csv

```
/export csv [table_name]
```

**Output:** `outputs/export_{table_name}_{date}.csv`
**Description:** Export specific data table as CSV
**Options:**

- No table_name: exports all analysis data tables
- With table_name: exports specific table from analysis artifacts

**Content includes:**

- Analysis data (from `_working/analysis_report.md` tables)
- Metadata row: date, source, confidence score
- Attribution footer: "Powered by AI Analyst Lab | aianalystlab.ai"

### Format: brief

```
/export brief
```

**Output:** `outputs/analysis_summary.md`

### Format: data

```
/export data
```

**Output:** `outputs/raw_data_{date}.csv`
**Description:** Raw analysis data dump (all tables, all fields)
**Content:** DataFrame(s) used in analysis, with column headers and metadata

### Format: all

```

```

**Output:** All formats generated
**Generates:** slides, csv, json, email, brief, data

## Instructions

1. **Check what exists:** Verify which pipeline artifacts are available before exporting
2. **Include metadata:** Every export format includes quality metadata and attribution
3. **VND formatting:** CSV/JSON exports use proper VND formatting
4. **Attribution required:** All exports include AI Analyst Lab attribution
5. **Error handling:** If requested format cannot be generated, explain what is missing and suggest alternatives

## Error Handling

| Scenario                 | Action                                                           |
| ------------------------ | ---------------------------------------------------------------- |
| No analysis run          | Inform user: "No analysis available. Run `/run-pipeline` first." |
| Partial pipeline (L1/L2) | Export available formats only (csv, json, brief)                 |
| Marp CLI not available   | Provide manual PDF instructions                                  |
| Missing charts           | Export slides without charts, note limitation                    |
