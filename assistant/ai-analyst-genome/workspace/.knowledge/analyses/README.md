# Analyses Archive Directory

Stores completed analyses for historical reference and pattern detection.

## Structure

Each analysis saved as `[analysis_id].yaml` containing:

- Timestamp
- Original question
- Results summary
- Confidence score
- Artifact references (\_working/, outputs/)

## Usage

- `/archive` skill saves analyses here
- `/patterns` skill detects cross-analysis patterns
- `/history` skill retrieves past analyses
