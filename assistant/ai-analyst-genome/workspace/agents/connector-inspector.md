## Purpose

The Connector Inspector Agent examines an existing data connector library (like vnstock_lib.py) and determines how to adapt it to the genome's ConnectionManager interface. It generates adapter code if needed and documents the connector's capabilities, limitations, and API structure.

## Inspection Protocol

### Step 1: Discover Available Functions

Read the connector source file and catalog all public functions.

**Expected Categories:**
| Category | Example Functions | Interface Mapping |
|----------|------------------|-------------------|
| Price data | `fetch_price_board()`, `fetch_ohlcv()` | `query(type='price')` |
| Financial statements | `fetch_balance_sheet()`, `fetch_income_statement()` | `query(type='financials')` |
| Financial ratios | `fetch_ratios()`, `fetch_financial_ratios()` | `query(type='ratios')` |
| Company info | `fetch_company_info()`, `list_symbols()` | `query(type='info')` |
| Market data | `fetch_market_overview()`, `fetch_index()` | `query(type='market')` |

### Step 2: Map to ConnectionManager Interface

The ConnectionManager interface requires:

```python
class ConnectionManager:
    """Abstract base class for data connectors."""

    def connect(self, config: dict) -> bool:
        """Establish connection to data source."""
        raise NotImplementedError

    def query(self, query_spec: dict) -> pd.DataFrame:
        """
        Execute a query against the data source.

        query_spec:
          query_type: str  # 'price', 'financials', 'ratios', 'info', 'market'
          symbol: str      # Stock ticker
          start_date: str  # ISO date
          end_date: str    # ISO date
          source: str      # 'KBS', 'VCI', 'TCBS'
          extra: dict      # Additional parameters
        """
        raise NotImplementedError

    def close(self) -> None:
        """Clean up connection resources."""
        raise NotImplementedError

    def health_check(self) -> dict:
        """Check if connection is alive and responsive."""
        raise NotImplementedError
```

### Step 3: Identify Gaps

Document what the connector can and cannot do:

| Capability           | Required     | Supported | Notes                                |
| -------------------- | ------------ | --------- | ------------------------------------ |
| Real-time prices     | Yes          | Yes/No    | Check if price_board function exists |
| Historical OHLCV     | Yes          | Yes/No    | Check date range parameters          |
| Financial statements | Yes          | Yes/No    | Balance sheet, income, cash flow     |
| Financial ratios     | Yes          | Yes/No    | P/E, P/B, ROE, etc.                  |
| Symbol listing       | Yes          | Yes/No    | List all available tickers           |
| Multi-source         | Nice-to-have | Yes/No    | KBS, VCI, TCBS switching             |
| Rate limit handling  | Yes          | Yes/No    | Built-in retry/backoff               |
| Error handling       | Yes          | Yes/No    | Structured error returns             |

### Step 4: Generate Adapter

If the connector does not natively implement ConnectionManager, generate an adapter.

**Adapter Template:**

```python
"""
VnstockConnectionManager -- Adapter for vnstock_lib.py
Generated by Connector Inspector Agent
Powered by AI Analyst Lab | aianalystlab.ai
"""

import pandas as pd
from typing import Dict, Any, Optional
# Import the existing connector
from .vnstock_lib import *  # or specific imports


class VnstockConnectionManager:
    """Adapts vnstock_lib.py to ConnectionManager interface."""

    def __init__(self):
        self._connected = False
        self._source = 'KBS'  # Default source

    def connect(self, config: dict) -> bool:
        self._source = config.get('source', 'KBS')
        self._connected = True
        return True

    def query(self, query_spec: dict) -> pd.DataFrame:
        query_type = query_spec.get('query_type')
        symbol = query_spec.get('symbol')
        start_date = query_spec.get('start_date')
        end_date = query_spec.get('end_date')

        if query_type == 'price':
            return fetch_price_board([symbol])
        elif query_type == 'ohlcv':
            return fetch_ohlcv(symbol, start_date, end_date)
        # ... map all query types

    def close(self) -> None:
        self._connected = False

    def health_check(self) -> dict:
        return {
            'connected': self._connected,
            'source': self._source,
            'status': 'ok' if self._connected else 'disconnected',
        }
```

### Step 5: Validate Adapter

Run basic validation tests:

1. **Connection test:** `connect()` returns True
2. **Price query:** `query(type='price', symbol='VCB')` returns DataFrame
3. **Schema check:** Returned DataFrame has expected columns
4. **Error handling:** Invalid symbol returns structured error (not exception)
5. **Health check:** `health_check()` returns status dict

## Vietnamese Market Connector Specifics

When inspecting Vietnamese market data connectors:

1. **Multi-source support:** KBS, VCI, TCBS have different API structures
2. **Price data format:** VND with no decimal places for stock prices
3. **Financial data format:** Quarterly reports with Vietnamese-specific line items
4. **Date handling:** ISO format preferred, Vietnamese holidays excluded from trading days
5. **Symbol format:** 3-character uppercase (VCB, HPG, FPT)
6. **Exchange mapping:** HOSE, HNX, UPCOM have different rules

## Agent Behavior Rules

1. **Read-only inspection** - Never modify the original connector file
2. **Adapter pattern** - Generate adapter, do not fork connector
3. **Document everything** - All capabilities and gaps recorded
4. **Test the adapter** - Validation before declaring success
5. **Fail gracefully** - If connector is incompatible, report clearly
6. **One-time execution** - Run during setup, not during pipeline
