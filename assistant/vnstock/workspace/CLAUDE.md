# Finance Research Assistant — Workspace

## First Run — Python Environment Setup

On first use, the workspace requires a one-time setup to install Python dependencies.
This is triggered automatically by the assistant. If you see a setup prompt, run:

```bash
bash setup.sh
```

What `setup.sh` does:

- Detects your system Python (3.11+ required)
- Installs `pydantic`, `requests`, `pandas`, `numpy`, `python-dotenv`, `httpx`
- Creates a `.initialized` marker file so setup is skipped on future runs

To re-run setup if something breaks:

```bash
rm .initialized && bash setup.sh
```

After setup, all `python` commands work as documented below.

## API Key Setup (Optional)

The Financial Datasets API provides **free tier** data for the following tickers without an API key:
`AAPL`, `GOOGL`, `MSFT`, `NVDA`, `TSLA`

For all other tickers, set your API key:

```bash
export FINANCIAL_DATASETS_API_KEY=your_key_here
```

## Dependencies

```bash
pip install requests pandas pydantic numpy python-dotenv dash
```

Or with pyproject.toml (Python 3.11+):

```bash
pip install -e .
```

## Interactive Dashboard

The workspace includes a Dash-based interactive dashboard at `app.py`.
Use the **Preview App** button in the workspace panel to open it, or launch manually:

```bash
python app.py
```

The dashboard runs at `http://localhost:8050` and provides:

- Live price charts with EMA overlays
- Financial metrics cards (market cap, P/E, margins, EPS)
- Revenue growth and margin trend charts
- Valuation multiples comparison
- Recent news feed

Enter any supported ticker and click **Analyze** to fetch live data.

## Report Workflow

Every analysis command produces a **self-contained folder** under `analyses/` that bundles the report, charts, and raw data together.

### Naming Convention

```
analyses/{TICKER}_{command}_{YYYY-MM-DD}/
```

Examples:

- `analyses/NVDA_trading-ideas_2026-02-19/`
- `analyses/AAPL_analyze_2026-02-19/`
- `analyses/macro_fed-policy_2026-02-19/`
- `analyses/MSFT_compare_GOOGL_2026-02-19/`
- `analyses/portfolio_2026-02-19/`

Each folder contains:

```
analyses/NVDA_analyze_2026-02-19/
├── report.md          # Final markdown report
├── charts/            # PNG charts generated by financial-visualization skill
│   ├── NVDA_price_2026-02-19.png
│   ├── NVDA_financials_2026-02-19.png
│   ├── NVDA_valuation_2026-02-19.png
│   └── NVDA_radar_2026-02-19.png
└── data/              # Raw JSON outputs from API + skill scripts
    ├── metrics.json
    ├── prices.json
    ├── news.json
    ├── insider.json
    └── ...
```

### Process (mandatory for every analysis)

1. **Read the sample** — before generating any report, read the corresponding sample in `analyses/samples/`
2. **Set ANALYSIS_DIR** — `ANALYSIS_DIR="analyses/${TICKER}_<command>_${TODAY}"` and `mkdir -p "$ANALYSIS_DIR/charts" "$ANALYSIS_DIR/data"`
3. **Run data scripts** — pipe JSON outputs to `$ANALYSIS_DIR/data/<name>.json` using `tee`
4. **Run chart scripts** — pass `$ANALYSIS_DIR/charts` as the OUTPUT_DIR argument
5. **Generate report** — structure report matching the sample's depth and specificity
6. **Save to disk** — write report to `$ANALYSIS_DIR/report.md`
7. **Reference in chat** — summarize key findings and end with `_Analysis saved to: analyses/..._`

### Save Command Pattern

```bash
# At the start of every command:
TICKER=NVDA
TODAY=$(date +%Y-%m-%d)
ANALYSIS_DIR="analyses/${TICKER}_trading-ideas_${TODAY}"
mkdir -p "$ANALYSIS_DIR/charts" "$ANALYSIS_DIR/data"

# Data fetching — save raw JSON alongside:
python .claude/skills/financial-data/scripts/get_metrics.py $TICKER $TODAY \
  | tee "$ANALYSIS_DIR/data/metrics.json"

# Chart generation — pass ANALYSIS_DIR/charts as output_dir:
python .claude/skills/financial-visualization/scripts/plot_price.py \
  $TICKER $ONE_YEAR_AGO $TODAY "$ANALYSIS_DIR/charts"

# Report save:
# Write full report content to $ANALYSIS_DIR/report.md
```

## Commands

| Command           | Usage                                                       | Description                                                                                       |
| ----------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `/research`       | `/research NVDA` or `/research macro then find tech stocks` | **Scenario-aware entry point** — classifies intent and routes to the right pipeline automatically |
| `/trading-ideas`  | `/trading-ideas NVDA`                                       | Institutional equity research with BUY/HOLD/SELL                                                  |
| `/analyze`        | `/analyze NVDA`                                             | Run all investor personas + full analytical stack                                                 |
| `/macro`          | `/macro fed policy`                                         | Global macro analysis (Fed, inflation, GDP, credit)                                               |
| `/compare`        | `/compare MSFT GOOGL`                                       | Side-by-side fundamental and technical comparison                                                 |
| `/screen`         | `/screen sector:tech pe:<20 momentum:high`                  | Screen stocks by factor criteria                                                                  |
| `/screen-canslim` | `/screen-canslim AI semiconductors`                         | CANSLIM screener with macro gate — finds growth-momentum stocks aligned with current regime       |
| `/portfolio`      | `/portfolio`                                                | Analyze holdings for risk and diversification                                                     |
| `/factors`        | `/factors`                                                  | Current factor premium landscape                                                                  |

### `/research` Scenario Taxonomy

`/research` classifies your query into one of 5 scenarios and executes the matching pipeline:

| Scenario      | Trigger Examples                                                       | Pipeline                                             | Output                                     |
| ------------- | ---------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------ |
| `deep-dive`   | `NVDA`, `analyze AAPL`, `full report on TSLA`                          | All skills + all 4 agents + charts + macro gate      | `_analyze_`-style report                   |
| `macro-first` | `macro first then find tech stocks`, `which stocks fit current regime` | Macro → sector screen → top 3 trade ideas            | macro report + 3 `_trading-ideas_` reports |
| `trade-idea`  | `should I buy TSLA`, `trade idea for MSFT`                             | Prices + metrics + news + technicals + Druckenmiller | `_trading-ideas_`-style report             |
| `compare`     | `MSFT vs GOOGL`, `compare AAPL or NVDA`                                | Parallel fundamentals + valuation + technicals       | `_compare_`-style report                   |
| `persona`     | `Buffett view on AAPL`, `what would Graham think of MSFT`              | That persona's skill script + agent                  | single-persona research note               |

## Multi-Agent Research Orchestration

For comprehensive analysis of Vietnamese stocks, spawn multiple specialist sub-agents in parallel. Each agent focuses on one analytical perspective and writes insights to `drafts/{agent_name}/insights.md`.

### Architecture

```
User Request → Main Agent (CLAUDE.md)
                    ↓
    ┌───────────────┼───────────────┐
    ↓               ↓               ↓
Macro Agent   Fundamental   Factor Agent
                Agent
    ↓               ↓               ↓
drafts/macro/ drafts/fundamentals/ drafts/factors/
    ↓               ↓               ↓
    └───────────────┼───────────────┘
                    ↓
            Aggregation Scripts
            (extract_metrics.py, generate_report.py)
                    ↓
            final_report.md
```

### Available Sub-Agents

| Agent               | Focus                                           | Writes To                         |
| ------------------- | ----------------------------------------------- | --------------------------------- |
| `macro-agent`       | Economic regime, sector implications            | `drafts/macro/insights.md`        |
| `fundamental-agent` | Financial statements, profitability, growth     | `drafts/fundamentals/insights.md` |
| `factor-agent`      | Quantitative factors (value, momentum, quality) | `drafts/factors/insights.md`      |
| `technical-agent`   | Price action, support/resistance, signals       | `drafts/technicals/insights.md`   |
| `valuation-agent`   | Intrinsic value, DCF, comparables               | `drafts/valuation/insights.md`    |
| `sentiment-agent`   | News sentiment, insider activity                | `drafts/sentiment/insights.md`    |

### Agent Selection Logic

| User Request                     | Agents to Spawn                    |
| -------------------------------- | ---------------------------------- |
| "full analysis of VCB"           | All 6 agents                       |
| "fundamental analysis of VCB"    | fundamental-agent, valuation-agent |
| "macro context then find stocks" | macro-agent first, then screen     |
| "quant factors for VCB"          | factor-agent, technical-agent      |
| "valuation only for VCB"         | valuation-agent                    |

### Execution Workflow

#### Step 1: Create Workspace

```bash
SYMBOL=VCB
TODAY=$(date +%Y-%m-%d)
ANALYSIS_DIR="analyses/${SYMBOL}_multiagent_${TODAY}"
mkdir -p "$ANALYSIS_DIR/drafts"/{macro,fundamentals,factors,technicals,valuation,sentiment}/{data,charts}
```

#### Step 2: Spawn Agents in Parallel

Use the Task tool with `run_in_background=true` to spawn multiple agents simultaneously. **CRITICAL**: All agent spawns must be in a SINGLE message with multiple Task tool calls.

Example for full analysis:

```
I'll spawn 6 specialist agents to analyze VCB comprehensively.
```

Then make 6 Task tool calls in ONE message:

1. **Macro Agent**

   ```
   Task(
     subagent_type="general-purpose",
     prompt="You are the Macro Regime Analyst. Follow .claude/agents/macro-agent.md to analyze Vietnam's macroeconomic environment. Write insights to analyses/VCB_multiagent_2026-02-20/drafts/macro/insights.md",
     run_in_background=true
   )
   ```

2. **Fundamental Agent**
   ```
   Task(
     subagent_type="general-purpose",
     prompt="You are the Fundamental Analyst. Follow .claude/agents/fundamental-agent.md to analyze VCB's financials. Symbol: VCB. Write insights to analyses/VCB_multiagent_2026-02-20/drafts/fundamentals/insights.md",
     run_in_background=true
   )
   ```

3-6. **Factor, Technical, Valuation, Sentiment Agents** - similar structure

#### Step 3: Monitor Agent Progress

```bash
# Check which drafts are complete
ls -la analyses/VCB_multiagent_2026-02-20/drafts/*/insights.md

# Or use TaskOutput to check background agents
```

#### Step 4: Aggregate Results

Once all agents complete:

```bash
cd analyses/VCB_multiagent_2026-02-20

# Extract key metrics to JSON
python ../../scripts/extract_metrics.py \
  --drafts drafts/ \
  --output summary.json

# Generate final report
python ../../scripts/generate_report.py \
  --drafts drafts/ \
  --symbol VCB \
  --output final_report.md
```

#### Step 5: Review and Deliver

Read `final_report.md` and present executive summary to user. Optionally generate PowerPoint deck.

### Guidelines for Main Agent

1. **Always create workspace** before spawning agents
2. **Spawn agents in parallel** when possible (single message, multiple Task calls)
3. **Monitor completion** via TaskOutput or file checks
4. **Aggregate systematically** using extract_metrics.py and generate_report.py
5. **Present executive summary** to user, save full report to disk
6. **Link macro to micro**: Use macro regime to guide factor selection

### Error Handling

If an agent fails:

- Check `drafts/{agent}/insights.md` exists
- Re-run that specific agent manually
- Continue with partial results (5/6 agents is still valuable)

### Customization

Users can request subset of agents:

```
"Just fundamental and valuation analysis for VCB"
→ Spawn only fundamental-agent and valuation-agent

"Macro context only"
→ Spawn only macro-agent

"Quant analysis for VCB"
→ Spawn factor-agent and technical-agent
```
